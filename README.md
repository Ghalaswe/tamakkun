# تمكّن – Tamkeen

> **منصة تدريب ذكية على المقابلات الوظيفية باستخدام الذكاء الاصطناعي.**

---

## 📌 نظرة عامة على المشروع (Project Overview)

**"تمكّن"** هي منصة تدريبية تساعد الباحثين عن عمل على الاستعداد للمقابلات الوظيفية عبر محاكاة مقابلة حقيقية باستخدام تقنيات الذكاء الاصطناعي.

يختار المستخدم المسمى الوظيفي الذي يحتاج إلى التدرب عليه ويحدد مستوى خبرته، ثم تبدأ المقابلة التجريبية ليطرح الذكاء الاصطناعي أسئلة مخصصة ومباشرة ذات صلة بالوظيفة. فور الانتهاء، يتلقى المستخدم تقييمًا تفصيليًا لأدائه، يوضح نقاط القوة ونقاط التحسين، إلى جانب توصيات واقتراحات لتطوير إجاباته.

> ⚠️ **تنبيه:** التقييم الموفر في المنصة ذو طابع تدريبي وإرشادي، ولا يُعد حكمًا نهائيًا على مدى أهلية المستخدم للوظيفة.

---

## ✨ المزايا الرئيسية (Main Features)

* **اختيار الوظيفة:** اختيار الوظيفة من قائمة معتمدة أو إدخال مسمى وظيفي مخصص.
* **تحديد الخبرة والأسئلة:** تحديد مستوى الخبرة وعدد أسئلة المقابلة.
* **مقابلة مخصصة:** إنشاء مقابلة مخصصة بالكامل باستخدام الذكاء الاصطناعي.
* **أسئلة متنوعة:** تقديم أسئلة متنوعة (عامة، سلوكية، وتقنية) متناسبة مع الوظيفة.
* **عرض متسلسل:** عرض الأسئلة بشكل متسلسل (سؤال واحد في كل مرة).
* **إجابات كتابية:** تقديم الإجابات بصيغة كتابية.
* **تقييم دقيق للإجابات وفق المعايير التالية:**
  * وضوح الإجابة.
  * صلة الإجابة بالوظيفة.
  * قوة المحتوى وصحته.
  * تنظيم الإجابة وترتيبها.
  * اكتمال الإجابة.
* **نتائج وتحليلات:**
  * تقديم النتيجة النهائية من 100.
  * عرض نقاط القوة وجوانب التحسين.
  * إتاحة اقتراحات عملية لتطوير الإجابات.
  * عرض لوحة نتائج توضح مستوى الجاهزية والاستعداد للمقابلة.
* **متابعة السجل:** إكانية إعادة التدرب على نفس الوظيفة ومقارنة النتائج بالمرّات السابقة مع الاحتفاظ بسجل مبسط للمقابلات التي جرى إتمامها.

## 🔄 مسار المستخدم (User Flow)

1. **الدخول** إلى منصة تمكّن.
2. **اختيار الوظيفة** المراد التدرب عليها.
3. **تحديد مستوى الخبرة**.
4. **تحديد عدد الأسئلة** المطلوبة.
5. **بدء المقابلة**.
6. **كتابة الإجابات** عن الأسئلة.
7. **تحليل الإجابات وتدقيقها** بوساطة الذكاء الاصطناعي.
8. **استعراض التقييم** والنتيجة النهائية.
9. **مراجعة نقاط القوة** ونقاط التحسين.
10. **إعادة المقابلة** عند الحاجة ومقارنة مستوى التطور.

## 🛠️ التقنيات وأدوات الذكاء الاصطناعي المستخدمة (Technologies & AI Tools Used)

تم تطوير المشروع باستخدام منصة **Manus** للمساعدة في بناء التطبيق.

* **التطوير (Development):** Manus
* **الاستضافة والنشر (Deployment):** GitHub / Render
* **الذكاء الاصطناعي (AI):** واجهة برمجة التطبيقات (AI API) المدمجة داخل التطبيق.

> 💡 **ملاحظة:** تنص وثيقة متطلبات المنتج (PRD) على استخدام **HTML/CSS/JavaScript** للواجهة الأمامية، و **Node.js** للواجهة الخلفية، مع قاعدة بيانات **Firebase** أو **Supabase**. أما تفاصيل التقنيات الفعلية المعتمدة في النسخة الحالية فتتطلب المطابقة مع ملفات المشروع.  
> تم اعتماد **Manus** في تطوير المشروع، وتم رفع المصدريات على **GitHub** ونشر التطبيق على **Render**.

## ⚙️ تعليمات التثبيت والتشغيل (Installation & Run Instructions)

### تشغيل المشروع محليًا:
عند تشغيل المشروع في البيئة المحلية، يُرجى اتباع التعليمات الموضحة في مستودع GitHub، والتي تتلخص في الخطوات الآتية:

1. **استنساخ (Clone)** المستودع من GitHub.
2. **تثبيت الحزم** والمتطلبات البرمجية اللازمة.
3. **إنشاء ملف البيئة (`.env`)** وإضافة المفاتيح الخاصة بالخدمات المستعملة.
4. **تشغيل الواجهة الخلفية** (Backend).
5. **تشغيل الواجهة الأمامية** (Frontend).
6. **فتح التطبيق** عبر المتصفح.

### 🔐 متغيرات البيئة (Environment Variables):
* يُمنع إدراج مفاتيح API أو البيانات الحساسة مباشرة داخل الكود البرمجي.
* يلزم استخدام متغيرات البيئة، مثل:
  ```env
  OPENAI_API_KEY=your_api_key_here
  ```
* **عدم رفع ملف `.env` إلى مستودع GitHub نهائيًا.**

## 💡 طريقة استخدام التطبيق (How to Use the Application)

1. افتح منصة **تمكّن**.
2. حدد الوظيفة المرغوبة.
3. حدد مستوى الخبرة المناسب.
4. اختر عدد الأسئلة.
5. ابدأ جلسة المقابلة.
6. أجب عن كل سؤال يُطرح عليك.
7. راجع النتيجة النهائية عند إتمام المقابلة.
8. اطلع على نقاط القوة ونقاط التحسين.
9. استعن بالملاحظات والتوصيات لتطوير أسلوب إجاباتك.
10. أعد المقابلة عند الحاجة لمتابعة مدى تقدمك ومقارنة نتيجتك الحالية بالنتائج السابقة.

## 🤖 تقييم الذكاء الاصطناعي (AI Evaluation)

يركز الذكاء الاصطناعي على تقديم تقييم تدريبي مباشر ومفهوم؛ حيث تُحلَّل الإجابات وفق معايير محددة مع إرفاق ملحوظات تطبيقية مساعدة.

**يلتزم النظام بما يلي:**
* طرح أسئلة مرتبطة بالوظيفة المحددة.
* مراعاة مستوى خبرة المستخدم.
* تجنب تكرار الأسئلة دون داعٍ.
* الامتناع عن تقديم معلومات غير صحيحة أو اختلاق تفاصيل عن الوظيفة.
* توضيح المبررات والمسببات الخاصة بكل تقييم.
* عدم إسناد درجات عشوائية دون تحليل أو تفسير.
